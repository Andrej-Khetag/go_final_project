Описание проекта

Веб-сервис планировщика задач, разработанный на языке Go в рамках дипломного проекта. Приложение представляет собой аналог TODO-листа с возможностью создания задач с различными правилами повторения.

Основная функциональность:
- Создание задач с указанием даты, заголовка и комментария
- Поддержка правил повторения задач (ежедневно, ежегодно)
- Автоматический расчет следующей даты выполнения для повторяющихся задач
- Получение списка ближайших задач (до 50 записей)
- Просмотр параметров конкретной задачи
- Редактирование существующих задач
- Веб-интерфейс для управления задачами
- Хранение данных в SQLite базе данных

Технологический стек:
- Backend: Go (стандартная библиотека net/http)
- База данных: SQLite (драйвер modernc.org/sqlite)
- Frontend: HTML, CSS, JavaScript (готовые статические файлы)

Инструкция по запуску кода локально

Предварительные требования:
- Go версии 1.19 или выше
- Доступ к интернету для загрузки зависимостей

Шаги для запуска:

1. Клонируйте репозиторий (если используете Git):
   
   git clone <url-репозитория>
   cd go_final_project

2. Установите зависимости:

   go mod download

3. Запустите сервер:
   
   go run main.go

4. Откройте в браузере:
   
   http://localhost:7540/

Конфигурация:
- Порт по умолчанию: 7540
- Файл базы данных: scheduler.db (создается автоматически в корневой директории)

Переменные окружения (опционально):
Вы можете настроить работу приложения через переменные окружения:

- Изменить порт сервера
export TODO_PORT=8080

- Указать путь к файлу базы данных
export TODO_DBFILE="./data/scheduler.db"

- Запуск с переменными окружения
TODO_PORT=8080 TODO_DBFILE="./my_scheduler.db" go run main.go

Непрерывная интеграция

Проект настроен для автоматического тестирования с помощью GitHub Actions. При каждом push автоматически запускается тест веб-сервера.

Конфигурация CI/CD находится в файле .github/workflows/tests.yml.

Инструкция по запуску тестов

Предварительная настройка:
1. Убедитесь, что сервер запущен на порту 7540
2. Настройте файл tests/settings.go:
   
   const (
       Port = ":7540"                    // Порт должен совпадать с портом сервера
       DBFile = "scheduler.db"           // Путь к тестовой базе данных
       FullNextDate = false              // Установить в false (правила со звёздочкой не реализованы)
   )

Команды для запуска тестов:

- Запуск всех тестов
go test ./tests

- Тестирование отдельных компонентов:

- Тестирование веб-сервера
go test -run ^TestApp$ ./tests

- Тестирование базы данных
go test -run ^TestDB$ ./tests

- Тестирование функции NextDate (правила повторения)
go test -run ^TestNextDate$ ./tests

- Тестирование добавления задач
go test -run ^TestAddTask$ ./tests

- Тестирование получения списка задач
go test -run ^TestTasks$ ./tests

- Тестирование получения задачи по ID
go test -run ^TestTask$ ./tests

- Тестирование редактирования задач  
go test -run ^TestEditTask$ ./tests

- Подробный вывод тестов
go test -v ./tests

Важные замечания:
- Перед запуском тестов убедитесь, что сервер запущен и доступен
- Параметр FullNextDate должен быть установлен в false
- Некоторые тесты могут изменять данные в базе данных
- Тесты создают временные файлы, которые удаляются автоматически

API Документация

GET /api/nextdate - вычисление следующей даты выполнения задачи
POST /api/task - добавление новой задачи
GET /api/tasks - получение списка ближайших задач
GET /api/task?id=<ID> - получение конкретной задачи по ID
PUT /api/task - редактирование существующей задачи
